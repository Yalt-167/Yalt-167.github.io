Description

A hangman game to learn Python

I made this game to learn Python. It's a hangman game drawn on a chalkboard, built with Pygame.

The player picks a word length between 3 and 9 letters, then guesses the word one letter at a time, with up to 11 wrong guesses while the drawing builds up on the board. Words come from a list of about 2,600 English words, and after a game, pressing "?" opens the word's translation on DeepL.

Content

The word list

A one-off script filters the original word list down to the words the game supports (3 to 9 letters), then the game groups the words by length in a dictionary and picks one at random for the length the player chose. 


from random import choice

def Pick(length : int) -> str:
    return choice(Read()[length])

def Read() -> dict[int,list[str]]:
    with open("Words/Words.txt","r") as words:
        wordsDict : dict[int,list[str]] = dict()
        for word in words:
            word = word.strip().lower()
            if len(word) in wordsDict:
                wordsDict[len(word)].append(word)
            else:
                wordsDict[len(word)] = [word]
    return wordsDict

def RemoveInvalidWords() -> None:
    with open("Words/InitialWords.txt","r") as words:
        with open("Words/Words.txt","w+") as txt:
            for word in words:
                word = word.strip().lower()
                if 2 < len(word) < 10:
                    txt.write(word + "\n")

Guesses

PlaceGuess() validates a guess and fills in every matching letter, using a generator to find them. Invalid guesses and letters already tried are reported by raising an exception, which the game loop catches to display the matching message for 120 frames (2 seconds at 60 FPS). 


def PlaceGuess(self, guess: str) -> bool:

    if len(guess) != 1: # should not occur
        raise AttributeError # would trigger InvalidGuess (outside the func)

    if guess in self.usedletters:
        raise NameError # would trigger AlreadyUsedLetter (outside the func)

    self.usedletters.append(guess)
    if guess in self.word:
        for idx in self.GetOccurencesOf(guess): # fill in the blank(s) associated with the current guess
            self.currentWord[idx] = guess
        return True

    self.wrongGuesses += 1
    return False

def GetOccurencesOf(self, char: str) -> Generator[int, None, None]:
    for idx in range(len(self.word)):
        if char == self.word[idx]:
            yield idx

# in the game loop
try:
    if guess not in self.alphabet:
        raise AttributeError # not a letter
    self.PlaceGuess(guess)

except NameError:
    self.timerToRenderWrongLetterErrorMessageAndLetter = [120, guess] # 2s cah 60FPS

except AttributeError:
    self.timerToRenderInvalidGuessMessage = 120 # 2s still

Fullscreen at any resolution

Everything is drawn on a fixed 1280x720 surface, which is scaled to the screen's actual size at the end of each frame. The game logic never has to care about the monitor's resolution: only the mouse position needs converting back into the fixed coordinates. 


def AdjustPos(self,mouse_XY : tuple[int,int]):
    # if im at (200,200) on my screen it may be (380,500) in computation coordinates due to resizing
    x, y = mouse_XY
    x /= (self.sizedDimension[0] / self.W)
    y /= (self.sizedDimension[1] / self.H)
    return x,y

def Draw(self): # render
    self.window = pg.transform.scale(self.window, (self.sizedDimension)) # resize fixed size display to actual dimensions
    self.display.blit(self.window, (0, 0)) # blit it on the actual screen
    pg.display.update() # render
    self.NewDisplay() # new fixed size display

What it taught me

Through this project I learned Python's style: dynamic typing with type hints, list and dictionary comprehensions, generators, f-strings, exceptions, and the if __name__ == "__main__" entry point.

Looking back, I would define my own exception classes instead of reusing NameError and AttributeError for game rules, and load the word list once instead of reading the file again for every new word.
